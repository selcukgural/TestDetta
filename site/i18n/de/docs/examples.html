Die Änderung

Eine Umbenennung im Paket für die deklarative Konfiguration: Das Flag, das angibt, ob OTEL_CONFIG_FILE überschrieben wird, bekommt einen Namen, der genau das sagt. Es ändert kein Verhalten, ist aber eine Codeänderung, daher würde eine normale Pipeline jedes Testprojekt im Repository bauen und ausführen.

Wie die Entscheidung zustande kam

{{name}} verfolgt die Änderung von der Datei bis zu den Tests, die sie bemerken können. Die geänderte Methode ist privat; nur UseDeclarativeConfiguration ruft sie auf. Die auf main aufgezeichnete Coverage-Map weiß, welche Testklassen sie ausgeführt haben: 8 Klassen in einem Testprojekt. Die übrigen 266 haben nichts davon ausgeführt und nennen nichts davon.
