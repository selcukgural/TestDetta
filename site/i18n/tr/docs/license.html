Önceki bir sürümden geçiyorsanız

{{name}}'nın önceki sürümleri özel depolarda bir lisans okuyordu. {{name}} artık hiçbir lisans okumaz ve seçim her zaman çalışır:

  • TESTDETTA_LICENSE, TESTDETTA_LICENSE_FILE, TESTDETTA_LICENSE_SCOPE, TESTDETTA_LICENSE_REFRESH ve ~/.testdetta/license yok sayılır. Secret'ı ve dosyayı silebilirsiniz.
  • td license status ve td license install komutları kaldırıldı.
  • GitHub Action, mevcut workflow'lar bozulmasın diye license girdisini hâlâ kabul eder, ama onu yok sayar ve log'da bunu belirtir. Uygun olduğunda workflow'unuzdan kaldırın.
  • td affected --format json çıktısında artık license alanı yoktur.
  • {{name}} hiçbir ağ çağrısı yapmaz: lisans yenilemesi artık yoktur.
