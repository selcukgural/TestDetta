GitHub Actions なら 2 ステップ

既定のブランチで一度記録すれば、以降のプルリクエストでは影響を受けるテストだけを実行します。

  1. main へのプッシュ時

    カバレッジマップを記録

    すべてのテストをカバレッジ付きで 1 回実行します。マップはコミットごとに Actions のキャッシュに保存されます。

  2. Actions のキャッシュ testdetta-coverage-<sha>
  3. プルリクエスト時

    変更が影響するテストを実行

    マージベースより前の 50 コミット以内で最新のマップを復元して、影響を受けるテストクラスだけを実行し、それぞれが実行された理由をジョブサマリーに示します。
