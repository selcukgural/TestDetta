項目要件
.NET SDK{{name}} 自体の実行には .NET 10 SDK を使用します。テストは、リポジトリで現在使用している SDK とテストランナーのまま実行されます。
Git の履歴マージベースを見つけられるよう、ブランチとそのターゲットブランチの完全な履歴が必要です。シャロークローンでは動作しません。

テストフレームワークとテストランナー

dotnet test の両方のテストランナーに対応しています。テストランナーは、dotnet test と同じように global.json から読み取られます。次の組み合わせは、記録を含めてエンドツーエンドでテストされており、各フレームワーク独自の並列実行を有効にした場合も確認しています。
