Dos pasos en GitHub Actions

Tu rama predeterminada registra una vez. Después, cada pull request ejecuta solo lo que afecta.

  1. en cada push a main

    Registrar un mapa de cobertura

    Todas las pruebas se ejecutan una vez, con cobertura. El mapa se guarda en tu caché de Actions bajo su commit.

  2. Caché de Actions testdetta-coverage-<sha>
  3. en cada pull request

    Ejecutar lo que afecta el cambio

    Se restaura el mapa más reciente en la merge base o antes, se ejecutan solo las clases de prueba afectadas y el job summary explica por qué se ejecutó cada una.
