Coming from an earlier version

Earlier versions of {{name}} read a license on private repositories. {{name}} now reads none, and selection always runs:

  • TESTDETTA_LICENSE, TESTDETTA_LICENSE_FILE, TESTDETTA_LICENSE_SCOPE, TESTDETTA_LICENSE_REFRESH and ~/.testdetta/license are ignored. You can delete the secret and the file.
  • The td license status and td license install commands are gone.
  • The GitHub Action still accepts its license input, so existing workflows keep working, but ignores it and says so in the log. Remove it from your workflow when convenient.
  • td affected --format json no longer has a license field.
  • {{name}} makes no network calls: there is no license refresh any more.
