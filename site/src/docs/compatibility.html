Target frameworks

The code under test can target any framework: {{name}} reads its source and rewrites its compiled assemblies while recording, whatever they target. What sets a limit is the test project, because recording runs inside its test host.

Languages

LanguageHow changes are handled
C#, Visual BasicAnalysed down to members: syntax trees, coverage maps and name tracing. Visual Basic names are matched ignoring case, and the project's root namespace is applied, as the compiler does.
F#Analysed like C#, down to members. Modules count as classes and their let functions as members, as the compiler builds them; indentation counts as code. An inline function is compiled into its callers, so they are found by name. Signature files (.fsi) are not analysed: a change to one runs everything that depends on its project.
