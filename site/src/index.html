Two steps in GitHub Actions

Your default branch records once. Every pull request then runs only what it affects.

  1. on push to main

    Record a coverage map

    Every test runs once, with coverage. The map is saved in your Actions cache under its commit.

  2. Actions cache testdetta-coverage-<sha>
  3. on pull request

    Run what the change affects

    The newest map at or before the merge base is restored, only the affected test classes run, and the job summary says why each one did.
